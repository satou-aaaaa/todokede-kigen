# 届け出いつまで？（todokede-kigen）

出生届・死亡届・転入届・犬の登録・相続の放棄・相続税の申告などの場面を読んで、届け出や手続きの期限（あらかじめ・7日以内〜10か月以内）を当てる1日5問の学習ゲーム。正解したら、どこに出すか（市区町村・税務署・そのほか）も選ぶ。暮らしの手続きや、社会・公民の学習に。

遊ぶ: <https://satou-aaaaa.github.io/todokede-kigen/>

- 中身は e-Gov 法令検索（<https://laws.e-gov.go.jp/>）の条文に書いてあることだけです。戸籍法・住民基本台帳法・狂犬病予防法・民法・健康保険法・国民健康保険法施行規則・国民年金法施行規則・死産の届出に関する規程・所得税法・相続税法・自動車の保管場所の確保等に関する法律・道路運送車両法を使っています（2026-11-17 に読みました）。
- 説明は条文を、短く言いかえたものです。書き方・必要な書類・手数料・遅れたときの過料・期間の数え方の細かい決まりは省いています。公式の情報の代わりではありません。実際の届け出は、市区町村・税務署などの窓口や公式サイトの案内で確かめてください。
- 出す先は、それぞれの条文に書いてある届け出の相手（市町村長・税務署長・家庭裁判所・警察署長など）で分けています。
